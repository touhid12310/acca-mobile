# AccountE promo videos

This folder holds the source for ten 56-second promo spots for AccountE (AI Money Tracker). Each spot comes in a 16:9 master and a re-composed 9:16 version. Everything is code, so any spot can be re-rendered frame-exactly.

| Doc | What it is |
|---|---|
| [`docs/01_RESEARCH_SUMMARY.md`](docs/01_RESEARCH_SUMMARY.md) | Research summary: sources, verified facts, flags, brand palette and fonts |
| [`docs/02_VIDEO_BRIEFS.md`](docs/02_VIDEO_BRIEFS.md) | The ten briefs with timed storyboards and the final VO scripts |
| [`docs/03_ASSETS.md`](docs/03_ASSETS.md) | Sourced asset list and licences |
| [`docs/04_DELIVERABLES.md`](docs/04_DELIVERABLES.md) | Per video: file names, one-line concept, title, caption, hashtags, QA result |
| [`docs/05_QA_REPORT.md`](docs/05_QA_REPORT.md) | Technical QA, pacing, claims rules, fonts, WCAG contrast, captions, safe zones and audio |

The rendered MP4s (`AccountE_NN_<Style>_<16x9|9x16>.mp4`, 10–26 MiB each) are delivered separately and are not committed.

## How it works

1. **Scenes.** Each spot is a web page at `videos/<id>/index.html` (generated by `tools/mkpage.py`). Animation lives in `video.js`. `lib/engine.js` builds one paused GSAP timeline and exposes `window.seek(t)`. Helpers:
   - `lib/kit.js`: motion helpers.
   - `lib/ui.js`: recreations of the AccountE Android UI, using sample data only.
   - `lib/brand.js`: the vectorized logo.
   - `lib/common.css`: tokens, captions and the shared end card.
2. **Voice-over.** `tools/vo.py` synthesizes each line in `videos/<id>/script.json` with Kokoro-82M (Apache-2.0). It checks that every line fits its beat and writes `out/<id>/vo.wav` plus `vo.js`, which drives the burned-in captions.
3. **Music and SFX.** `tools/music.py` composes an original track per style using `tools/synth.py` and `tools/instruments.py` (pure numpy). `tools/sfx.py` renders the sound cues each page registers with `E.cue()`.
4. **Frames.** `tools/render.mjs` opens the page in headless Chromium, seeks to every frame (30 fps) and pipes the frames into ffmpeg (H.264, yuv420p).
5. **Mix and mux.** `tools/mix.py` mixes VO, ducked music and SFX, loudness-normalizes to −16 LUFS / −1.5 dBTP, and writes `deliver/AccountE_NN_<Style>_<ar>.mp4`.
   Any file over 28 MiB is re-encoded two-pass to 26 MiB by `tools/fit.sh`, so every spot fits social and messaging upload limits.
6. **QA.**
   - `tools/qa.py` checks resolution, fps, duration, loudness, true peak and freezes, and writes contact strips.
   - `tools/contrast.py` checks the WCAG pairs.
   - `tools/deliverables.py` regenerates docs 04 and 05 from those results.

## Setup

```bash
cd marketing/promo-videos
npm install                       # gsap, three, fonts, icons, flag-icons, world-atlas, playwright
npx playwright install chromium   # or point PLAYWRIGHT_PATH at an existing playwright module
pip install numpy scipy soundfile kokoro-onnx
# Kokoro model files (not committed): kokoro-v1.0.onnx + voices-v1.0.bin from
# https://github.com/thewh1teagle/kokoro-onnx/releases → put them in $TTS_DIR (default ../tts)
```

ffmpeg (with libx264 and the `ebur128`/`loudnorm` filters) must be on `PATH`.

## Render

```bash
python3 tools/vo.py 10_minimal                    # VO + captions
python3 tools/music.py 10_minimal                 # music
node tools/render.mjs --still 1.5,24.5 10_minimal:16x9 10_minimal:9x16   # spot-check stills
tools/queue.sh 10_minimal                         # full render (both ARs) → mix → size fit → QA
python3 tools/deliverables.py docs                # refresh docs 04 and 05
```

`tools/render.mjs` launches Chromium with SwiftShader, so 3D scenes render the same on machines without a GPU. One spot takes about 5 minutes per aspect ratio on 4 cores; the 3D spot (03) takes about 20 minutes.

## Rules baked into the content

- Claims come only from the sources listed in doc 01. The videos show no prices, testimonials, counters, download numbers, ratings or awards. There are no competitor names and no App Store badge. Platforms are Android + Web.
- Every figure is sample data (persona "Alex", neutral merchants). No personal data or third-party brand names from the reference screenshots appear.
- Each spot uses at most two font families. Captions are burned in. 9:16 versions are re-composed so captions sit above the bottom 470 px.
